# 2026-11-21 三市场实验

三个种子均使用相同的市场面板、日期、标签和交易规则。每组包含 Adapter 持续学习基线 `A`、120 日修正和 60 日修正。60 日与 120 日指关系估计窗口，模型输入仍为 90 日，预测为 10 步。预测任务及在线更新时点见 [模型说明](../docs/method.md)。

## Endpoint 与 Path

下表统计 60 日方案相对 `A` 的三种子平均变化。RankIC 使用原量纲，净累计收益差使用百分点。方括号为 10 日配对区块 bootstrap 的 95% 区间。

| CSI300 | 0.025 | Endpoint | +0.000119 [0.000006, 0.000249] | +0.98 [−1.45, 4.91] |
| CSI300 | 0.025 | Path | +0.000099 [0.000013, 0.000202] | +0.15 [−0.18, 0.67] |
| Nasdaq-100 | 0.025 | Endpoint | +0.000019 [−0.000255, 0.000299] | +1.16 [−1.10, 4.97] |
| Nasdaq-100 | 0.025 | Path | +0.000068 [−0.000146, 0.000331] | −0.11 [−2.22, 2.30] |

每次 bootstrap 在同一市场内对方法和三个种子使用相同的日期块，共 5,000 次；净累计收益先分别复利复算，再取差值。CSV 另含 20 日块敏感性结果和与 120 日对照的配对比较。所列区间为逐项区间，适用于这一历史面板上的探索性比较。市场数据使用留存股票池，结果可能受成分股选择与存活偏差影响。组合假设可按信号日收盘持仓并获得下一交易日收盘收益，包含固定交易费率，成交约束和滑点需要另行评估。
