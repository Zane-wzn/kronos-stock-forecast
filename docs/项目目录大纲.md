# 项目目录大纲

本文档描述当前仓库的 GitHub 目录布局。实验结果统一归档到 `experiments/`，可直接浏览的图表和摘要统一归档到 `results/`；代码、文档和数据说明分别位于对应的职责目录。

## 1. 当前结构

```text
kronos-stock-forecast/
├─ README.md                              # 项目说明、数据准备和复现入口
├─ requirements.txt                       # 标准依赖安装入口
├─ requirements_venv_lock.txt             # 已验证环境的精确版本
├─ .gitignore / .gitattributes            # 忽略规则和大文件策略
├─ data/                                  # 数据说明、清单和校验信息
├─ third_party/Kronos_official_src/      # Kronos 官方源码快照
├─ src/                                   # 可复用模型、运行器和 CPU 基线
├─ continual_abcs/                        # Continual ABC 排序头和组合逻辑
├─ scripts/                               # 实验、评估、数据和审计入口
├─ figures/                               # 图表和 dashboard 生成脚本
├─ tests/                                 # 单元测试和实验协议测试
├─ docs/                                  # 实验协议、指标定义和审计记录
│  ├─ 股票预测评估指标整理.md              # 指标定义
│  ├─ 项目目录大纲.md                      # 本文档
│  └─ references/                         # 本地参考论文（不入库）
├─ experiments/                           # 所有当前实验产物的统一根目录
│  ├─ csi300_aligned/                     # CSI300 对齐模型比较
│  ├─ csi300_backtest/                    # CSI300 组合回测
│  ├─ continual/                          # 持续学习与多种子实验
│  ├─ sp500/                              # S&P500 对照实验
│  └─ references/                         # 合并面板和共享参考结果
└─ results/                               # 少量可直接审阅的 HTML 和聚合摘要
```

## 2. 数据和上游源码

| 路径 | 内容 | 仓库策略 |
|---|---|---|
| `data/csi300_daily/` | CSI300 日线数据说明和本地数据入口 | 原始行情按 `.gitignore` 规则管理 |
| `data/csi800_daily/` | CSI800 日线数据说明和本地数据入口 | 原始行情按 `.gitignore` 规则管理 |
| `data/yahoo_sp500/` | S&P500 数据说明和本地数据入口 | 原始行情按 `.gitignore` 规则管理 |
| `third_party/Kronos_official_src/` | Kronos 官方源码快照 | 保留源码和许可证 |
| `experiments/*/reference/` | 日期边界、股票清单、面板和缓存说明 | 提交轻量配置与摘要 |

正式 CSI300 面板以数据清单和 `experiments/csi300_aligned/reference/` 中的配置为准；运行前请准备 README 所列的本地 CSV 数据。

## 3. 代码入口

| 路径 | 作用 |
|---|---|
| `scripts/experiments/` | Kronos、Adapter、Continual ABC、ODEStream 和组合回测入口 |
| `scripts/evaluation/` | 指标重算、横截面排序和结果汇总 |
| `scripts/audit/` | 数据切分、缓存、持续更新和结果完整性审计 |
| `src/` | 可复用的模型、数据和评估组件 |
| `continual_abcs/` | 持续排序头、奖励、更新和组合评估逻辑 |
| `figures/` | 累计收益率、实验 dashboard 和静态图生成器 |

推荐入口见 `README.md` 和 `scripts/README.md`。根目录不再保留实验脚本，旧 recent50 流水线已于 2026-10-10 移除。

## 4. 实验布局

```text
experiments/
├─ csi300_aligned/
│  ├─ reference/                         # 数据边界、股票清单、共享参考文件
│  └─ models/
│     ├─ zero_shot/                       # Kronos zero-shot
│     ├─ linear_head/                     # 线性预测头
│     ├─ prediction_adapter/              # Prediction Adapter
│     ├─ ranking_adapter/                 # Ranking Adapter
│     ├─ adapter_continual/               # Adapter + Continual
│     ├─ continual_abc/                   # Continual ABC
│     ├─ continual_abc_mae_gate_tol001/   # MAE gate 变体
│     └─ odestream_direct_24x1/           # 独立 ODEStream，不接入 Kronos
├─ csi300_backtest/top10pct_drop3/        # Top10%/Drop3 统一回测
├─ continual/                             # 多种子和跨市场持续学习
├─ sp500/                                 # S&P500 参考面板和持续学习结果
└─ references/                            # 合并面板、恢复报告和共享指标
```

不同实验必须放在 `experiments/` 下独立的子目录中。正式结果目录应保留 `run_config.json` 或等价配置、摘要指标、日志以及必要的预测或 checkpoint 说明；大规模明细和缓存是否提交由 `.gitignore` 与 `.gitattributes` 统一控制。

## 5. 统一结果文件

常见结果文件包括：

| 文件 | 内容 |
|---|---|
| `run_config.json` | 数据、日期、窗口、模型和更新规则 |
| `summary.json` 或 `*_summary.md` | 实验摘要和主要指标 |
| `predictions.csv` 或 `rolling_predictions_all.csv` | 逐样本预测明细 |
| `daily_metrics.csv` / `*_metrics_by_date.csv` | 逐日误差、方向和横截面指标 |
| `portfolio_summary.csv` | 组合收益、回撤、Sharpe 等汇总 |
| `*.pt` | 模型 checkpoint |

横截面 IC、RankIC、TopK、BottomK 和 LongShort 必须按同一预测日期及预测步长计算。不同窗口、标签、股票池或交易规则的实验不能直接混合排名。

## 6. 复现和维护

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
pytest
```

运行前从仓库根目录执行脚本，并显式指定 `experiments/` 下的输出目录。首次使用 Kronos 时，按脚本提示准备官方源码、模型权重和 tokenizer。

提交新实验时：

1. 为实验建立语义清晰的独立子目录，不覆盖其他模型结果。
2. 保存参数、日期边界、数据切分、更新规则和指标口径。
3. 把可直接审阅的 HTML 和摘要放到 `results/` 的对应分类目录。
4. 不提交虚拟环境、缓存、个人路径和无法复现的临时文件。
