# 股票预测评估指标整理（公式纯文本版）

> 说明：这一版专门避免公式乱码。所有公式都用普通文本/代码块表示，不依赖 LaTeX 渲染，适合直接打开、复制到 Word 或 PPT。

## 1. Kronos 论文中的评估思路

Kronos 论文不是只看“价格预测准不准”，而是从三类能力评价金融时间序列模型：

| 能力 | 代表指标 | 说明 |
|---|---|---|
| 点预测能力 | MAE、MSE、RMSE、R2 | 预测值和真实值有多接近 |
| 排序/选股能力 | IC、RankIC | 模型能不能把未来表现好的股票排到前面 |
| 交易可用性 | AER、IR、Sharpe、最大回撤 | 预测信号进入交易策略后是否真的有收益，风险是否可控 |

Kronos 论文中的典型评估任务：

- 价格序列预测：使用 IC、RankIC。
- 收益率预测：使用 IC、RankIC。
- 实现波动率预测：使用 MAE、R2。
- 投资模拟：使用 AER、IR。
- 合成 K 线生成：使用 Diversity、Fidelity、Usefulness。

组会汇报时可以这样理解：

> MAE/RMSE 说明“预测价格有多准”；IC/RankIC 说明“选股排序有没有用”；AER/IR/Sharpe/最大回撤说明“拿去交易是否真的有效”。

## 2. 通用符号

| 符号 | 含义 |
|---|---|
| y_i | 第 i 个真实值 |
| yhat_i | 第 i 个预测值 |
| e_i | 误差，e_i = y_i - yhat_i |
| n | 测试样本数量 |
| y_bar | 所有真实值的平均值 |
| s_jt | 股票 j 在时间 t 的预测信号 |
| r_jt | 股票 j 未来真实收益率 |
| R_t | 策略在 t 期的收益率 |
| B_t | 基准在 t 期的收益率 |
| R_f | 无风险收益率 |
| K | 年化周期数，日频通常取 252 |

## 3. 点预测误差指标

### 3.1 MAE：平均绝对误差

公式：

```text
MAE = (1 / n) * sum(|y_i - yhat_i|)
```

含义：平均每个预测点偏离真实值多少。

例子：如果预测收盘价，MAE = 2 表示平均每个预测点错 2 元。

揭示的性能：

- 看模型平均预测误差。
- 对异常值不如 RMSE 敏感。
- 适合回答“模型平均错了多少”。

局限：

- 不反映误差方向。
- 不适合直接比较不同价格量级的股票。

### 3.2 MSE：均方误差

公式：

```text
MSE = (1 / n) * sum((y_i - yhat_i)^2)
```

含义：把每个误差平方后再取平均。

揭示的性能：

- 对大误差惩罚很重。
- 可以发现模型是否偶尔出现严重预测偏离。
- Kronos 消融实验中，连续空间 Direct-AR 基线使用 MSE 作为训练目标。

局限：

- 单位是原始单位的平方，不直观。
- 容易被极端行情或异常值放大。

### 3.3 RMSE：均方根误差

公式：

```text
RMSE = sqrt((1 / n) * sum((y_i - yhat_i)^2))
```

含义：MSE 开平方，单位回到原始变量单位。

揭示的性能：

- 既容易解释，又能强调大误差。
- 如果 RMSE 明显大于 MAE，说明存在少数很大的预测错误。

局限：

- 仍然受股价尺度影响。
- 对极端波动比较敏感。

### 3.4 MAPE：平均绝对百分比误差

公式：

```text
MAPE = (100% / n) * sum(|(y_i - yhat_i) / y_i|)
```

含义：误差占真实值的百分比。

例子：MAPE = 8% 表示平均相对误差约为 8%。

揭示的性能：

- 方便比较不同股票，因为它消除了价格单位。
- 适合回答“相对误差有多大”。

局限：

- 当 y_i 很小或接近 0 时会失真。
- 对低价股更敏感。

### 3.5 SMAPE：对称平均绝对百分比误差

公式：

```text
SMAPE = (100% / n) * sum(2 * |y_i - yhat_i| / (|y_i| + |yhat_i|))
```

含义：用真实值和预测值的平均尺度来衡量相对误差。

揭示的性能：

- 比 MAPE 更对称。
- 可以缓解真实值很小时 MAPE 过度放大的问题。

局限：

- 当真实值和预测值都接近 0 时仍可能不稳定。
- 不如 MAE/RMSE 直观。

### 3.6 R2：决定系数

公式：

```text
R2 = 1 - sum((y_i - yhat_i)^2) / sum((y_i - y_bar)^2)
```

含义：模型相比“永远预测均值”这个基线，解释了多少真实波动。

解释：

- R2 = 1：完美预测。
- R2 = 0：和预测均值差不多。
- R2 < 0：比预测均值还差。

揭示的性能：

- 看模型是否真正解释了真实变化。
- Kronos 论文在实现波动率预测中使用 MAE 和 R2。

局限：

- 股票价格非平稳，R2 有时不容易解释。
- 测试窗口太短时，R2 可能非常不稳定。

## 4. 方向与命中类指标

### 4.1 Directional Accuracy：方向准确率

价格预测公式：

```text
DA = 正确方向次数 / 总预测次数

正确方向：
sign(y_i - y_{i-1}) = sign(yhat_i - y_{i-1})
```

收益率预测公式：

```text
DA = count(sign(r_i) = sign(rhat_i)) / n
```

含义：模型预测涨跌方向是否正确。

揭示的性能：

- 看模型能不能判断上涨/下跌。
- 对交易很重要，因为交易首先关心方向。
- 你的本地脚本中的 `directional_accuracy_pct` 就是这个指标。

局限：

- 不考虑涨跌幅大小。
- 如果市场长期单边上涨，简单预测上涨也可能方向准确率较高。

### 4.2 Hit Rate：误差阈值命中率

公式：

```text
HitRate_epsilon =
count(|(y_i - yhat_i) / y_i| <= epsilon) / n
```

常用阈值：

```text
epsilon = 1%、2%、5%
```

含义：预测值落在真实值允许误差范围内的比例。

例子：Hit Rate 5% = 40%，表示有 40% 的预测点相对误差不超过 5%。

揭示的性能：

- 直观看模型有多少预测“足够接近”。
- 适合 PPT 展示。

局限：

- 阈值有主观性。
- 不区分刚刚超出阈值和严重错误。

## 5. 横截面选股指标

股票预测常常不是为了精确预测某一只股票价格，而是为了排序：哪些股票未来更可能涨得好。

### 5.1 IC：信息系数

公式：

```text
IC_t = corr(s_jt, r_jt)
```

其中：

```text
s_jt = 股票 j 在时间 t 的预测信号
r_jt = 股票 j 未来真实收益率
corr = Pearson 相关系数
```

多天平均：

```text
IC_mean = mean(IC_t)
```

含义：预测信号和未来收益之间的线性相关程度。

解释：

- IC > 0：信号有正向预测能力。
- IC = 0：信号基本没用。
- IC < 0：信号可能反向有效。

揭示的性能：

- 看模型输出的信号是否真的和未来收益相关。
- Kronos 论文在价格预测和收益率预测中都使用 IC。

局限：

- Pearson 相关对异常值敏感。
- IC 高不等于策略一定赚钱，还要考虑交易成本和风险。

### 5.2 RankIC：秩信息系数

公式：

```text
RankIC_t = corr(rank(s_jt), rank(r_jt))
```

其中：

```text
rank(s_jt) = 预测信号排序
rank(r_jt) = 未来真实收益排序
corr = Spearman 秩相关
```

含义：模型预测的股票排序和真实未来收益排序是否一致。

揭示的性能：

- 看模型能不能把未来表现好的股票排到前面。
- 对选股任务比普通 IC 更重要。
- Kronos 论文非常重视 RankIC，并报告其价格预测 RankIC 有显著提升。

局限：

- 只看排序，不看收益差距。
- RankIC 高仍然需要通过回测验证交易价值。

### 5.3 ICIR：IC 信息比

公式：

```text
ICIR = mean(IC_t) / std(IC_t)
```

年化形式：

```text
ICIR_annual = mean(IC_t) / std(IC_t) * sqrt(K)
```

含义：IC 是否稳定。

揭示的性能：

- 平均 IC 高但波动大，ICIR 可能不高。
- ICIR 高说明信号不仅有效，而且比较稳定。

局限：

- 依赖样本长度。
- 市场风格变化会影响 ICIR 的稳定性。

## 6. 波动率预测指标

### 6.1 Realized Volatility：实现波动率

公式：

```text
RV_t = sqrt(sum(r_tk^2))
```

其中：

```text
r_tk = 第 t 天内第 k 个高频收益率
```

含义：用日内高频收益率平方和衡量真实发生的波动。

常见评估公式：

```text
MAE_vol = (1 / n) * sum(|RV_i - RVhat_i|)

R2_vol = 1 - sum((RV_i - RVhat_i)^2) / sum((RV_i - RV_bar)^2)
```

揭示的性能：

- 衡量模型预测风险/波动的能力。
- Kronos 论文在实现波动率预测中使用 MAE 和 R2。

## 7. 投资回测指标

### 7.1 预测收益信号

Kronos 论文中的思想：先预测未来多天价格，再把未来预测均价与当前价格比较，形成选股信号。

公式：

```text
signal_jt =
(average(yhat_price_{j,t+1} ... yhat_price_{j,t+H}) - price_{j,t})
/ price_{j,t}
```

含义：

- signal > 0：模型认为未来均价高于当前价格。
- signal 越大：模型越看好这只股票。

### 7.2 Total Return：总收益率

公式：

```text
TR = (V_T - V_0) / V_0
```

含义：回测期内总共赚了多少。

揭示的性能：

- 最直观的盈利能力。

局限：

- 不说明收益是否稳定。
- 不说明承担了多少风险。

### 7.3 Annualized Return：年化收益率

公式：

```text
AR = (V_T / V_0)^(K / T) - 1
```

其中：

```text
K = 一年交易期数，日频通常为 252
T = 回测期交易日数
```

含义：把回测期收益折算成年化水平。

### 7.4 AER：年化超额收益

公式：

```text
AER = annualized(R_t - B_t)
```

含义：策略相对基准指数的年化超额收益。

揭示的性能：

- 看策略是否跑赢市场基准。
- Kronos 论文投资模拟使用 AER 作为核心指标。

局限：

- 依赖基准选择。
- 不反映超额收益波动。

### 7.5 Volatility：年化波动率

公式：

```text
Volatility_annual = std(R_t) * sqrt(K)
```

含义：策略收益序列的波动程度。

揭示的性能：

- 收益是否平稳。
- 波动越大，策略体验越不稳定。

### 7.6 Sharpe Ratio：夏普比率

公式：

```text
Sharpe = mean(R_t - R_f) / std(R_t - R_f)
```

年化形式：

```text
Sharpe_annual = mean(R_t - R_f) / std(R_t - R_f) * sqrt(K)
```

含义：每承担一单位总风险，获得多少超过无风险利率的收益。

揭示的性能：

- 风险调整后的收益能力。
- Sharpe 越高，说明收益相对于波动越划算。

局限：

- 用波动率代表风险，但金融收益常有极端亏损和肥尾分布。

### 7.7 IR：信息比率

公式：

```text
IR = mean(R_t - B_t) / std(R_t - B_t)
```

年化形式：

```text
IR_annual = mean(R_t - B_t) / std(R_t - B_t) * sqrt(K)
```

含义：每承担一单位相对基准的主动风险，获得多少超额收益。

揭示的性能：

- 比 Sharpe 更适合主动选股策略。
- Kronos 论文投资模拟使用 IR 作为核心指标。

局限：

- 强依赖基准选择。
- 需要结合行业、市值、风格暴露一起解释。

### 7.8 Maximum Drawdown：最大回撤

公式：

```text
running_peak_t = max(V_0, V_1, ..., V_t)

drawdown_t = (V_t - running_peak_t) / running_peak_t

MDD = min(drawdown_t)
```

通常汇报时取绝对值：

```text
MaxDrawdown = abs(MDD)
```

含义：资金曲线从历史高点到后续低点的最大亏损幅度。

揭示的性能：

- 衡量策略最痛苦的亏损。
- 实盘中非常重要。

### 7.9 Win Rate：胜率

公式：

```text
WinRate = count(trade_return > 0) / count(all_trades)
```

含义：盈利交易占所有交易的比例。

揭示的性能：

- 信号单笔交易成功频率。

局限：

- 胜率高不一定赚钱。
- 必须结合平均盈亏比、总收益、最大回撤一起看。

### 7.10 Turnover：换手率

公式：

```text
Turnover_t = sum(|w_jt - w_j,t-1|) / 2
```

其中：

```text
w_jt = 股票 j 在时间 t 的组合权重
```

含义：组合调仓幅度。

揭示的性能：

- 交易是否过于频繁。
- 换手越高，交易成本和滑点影响越大。

## 8. 合成 K 线生成指标

Kronos 论文还评价了合成 K 线生成质量。

### 8.1 Diversity：多样性

含义：生成样本是否覆盖真实市场的多种状态。

揭示的性能：

- 判断模型是否只会生成少数几种固定形态。
- 防止生成模型出现模式坍缩。

### 8.2 Fidelity：保真度

含义：生成数据是否像真实金融 K 线。

常见评价方式：

```text
训练一个分类器区分真实数据和生成数据。
如果分类器越难区分，说明生成数据越真实。
```

揭示的性能：

- 生成样本是否具有真实市场统计特征。

### 8.3 Usefulness：有用性

公式/协议：

```text
TSTR = Train on Synthetic, Test on Real
```

含义：用合成数据训练模型，再在真实数据上测试。

揭示的性能：

- 生成数据是否真的能帮助下游预测任务。
- 不是看起来像就够，还要对真实任务有用。

## 10. 汇报推荐指标组合

### 如果汇报收盘价预测

推荐指标：

```text
MAE、RMSE、MAPE、SMAPE、Directional Accuracy、Hit Rate
```

可选指标：

```text
R2
```

### 如果汇报收益率/涨跌预测

推荐指标：

```text
Directional Accuracy、IC、RankIC、ICIR
```

### 如果汇报选股策略

推荐指标：

```text
AER、IR、Sharpe、Maximum Drawdown、Turnover
```

### 如果汇报波动率预测

推荐指标：

```text
MAE、RMSE、R2
```

## 11. 一句话速记

| 指标 | 一句话理解 |
|---|---|
| MAE | 平均错多少 |
| MSE | 大错误会被平方放大 |
| RMSE | 和 MAE 类似，但更重视大错误 |
| MAPE | 平均相对误差百分比 |
| SMAPE | 更对称的相对误差 |
| R2 | 是否比预测均值更好 |
| Directional Accuracy | 涨跌方向猜对多少 |
| Hit Rate | 预测落在允许误差范围内的比例 |
| IC | 预测信号和未来收益是否相关 |
| RankIC | 预测排序和真实收益排序是否一致 |
| ICIR | IC 是否稳定 |
| AER | 相对基准一年多赚多少 |
| Sharpe | 每承担一单位总风险赚多少 |
| IR | 每承担一单位主动风险赚多少超额收益 |
| Maximum Drawdown | 最惨时从高点亏了多少 |
| Turnover | 调仓有多频繁 |
