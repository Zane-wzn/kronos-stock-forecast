# 复现指南

## 范围与环境

本项目复用现有实验归档完成跨股票修正和重评估。精确回放依赖对应的历史权重、缓存和监督日志。Git 中提供聚合结果、实验源码和可独立运行的单元测试。数据和归档文件的布局见 [数据契约](../data/README.md)。

原本地环境为 Python 3.12.4、NumPy 2.4.4、pandas 2.2.2、SciPy 1.17.1、PyTorch 2.5.1+cu124。CSI300 入口使用 CPU，美股入口使用 `cuda:0`。美股逐日重放启用确定性计算，严格对齐历史预测，因此更换设备或 PyTorch 版本可能导致数值断言失败。

| --- | --- | --- | --- | ---: | --- |
| CSI300 | 2016-05-17 至 2024-12-13 | 2025-01-02 至 2025-06-13 | 2025-07-01 至 2026-06-05 | 66,103 | 30 / 3 |

表内日期为预测起点。测试标签成熟时间最晚为 2026-06-22。原始训练和验证切分含期限隔离，验证标签最晚分别于 2025-06-27（CSI300）和 2025-06-30（美股）成熟。

## 运行

准备好 `.peer_pca_inputs/` 后，在项目根目录执行。每次选择新的运行目录。

```bash
python -m pytest -q
python scripts/experiments/run_peer_pca_60d_csi300.py --out last_try/runs/csi300-local
python scripts/experiments/run_peer_pca_60d_us.py --alpha 0.025 --out last_try/runs/us-alpha0025-local
python scripts/experiments/run_peer_pca_60d_us.py --alpha 1 --out last_try/runs/us-alpha1-local
```

两个美股命令均将原 α = 1 的指标表作为核对输入。在完整的历史工作区中，此表与 120 日对照已经存在。每次运行输出逐种子指标、均值与样本标准差、配对区间、校验 JSON 和本地预测文件。将结果与 [提交的三组汇总](../results/README.md)比较时，用 `market, seed, signal, model` 对齐。

## 来源

主线来源为同一项目本地分支 `experiment/cross-stock-residual-20261117`，基线代码快照为 `a589a27`，加上工作区中 2026-11-21 的 60 日实验脚本和三组结果。源码在本分支按回放依赖整理。三个结果目录的 CSV 保留原始内容。审计 JSON 中的机器绝对路径已换成项目路径或对应的原始运行标识。
